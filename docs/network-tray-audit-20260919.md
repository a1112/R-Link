# 设备网络与托盘审查（2026-09-19）

## 已修复

- 设备页面使用固定示例、连接仅弹提示：替换为受服务访问控制保护的设备 CRUD、SQLite 持久化、真实 TCP 检测和 SSH 地址带入。端口检测有 3 秒超时、8 个并发上限、单设备去重；参数限制与数据库唯一约束覆盖非法地址、端口和重复登记。旧探测结果不能覆盖编辑后的设备，删除后的设备不会被恢复。
- 仪表盘随机流量和固定活跃隧道数：移除虚构指标，使用服务端网卡计数与实际采样间隔计算 Mbps；网卡切换、计数归零、重启及长时间无采样时重建基线。拓扑图明确标记为演示。
- 系统和插件轮询重叠、旧响应覆盖、断线仍显示旧值：统一为单次请求完成后再调度的轮询，卸载时取消，目标变化时丢弃旧响应，失败时清除过期数据。
- SSH 页面切换即断连：保持终端页面挂载，返回时调整终端尺寸。修复父组件更新回调后意外重连、重试计时器未取消、WebSocket accept 失败泄漏连接名额；SSH 增加 30 秒保活、3 次失败上限和终端创建超时。
- 托盘开关和开机启动开关原为静态图形：通用设置替换为真实托盘设置，移除未实现的自启动假开关。补回无边框窗口的关闭、最小化和最大化按钮。

## 桌面行为

原生托盘提供显示、设备管理、SSH、设置、隐藏、关闭驻留切换和退出。关闭驻留默认开启，原生配置持久保存；托盘初始化失败时保留正常退出路径。单实例插件最先初始化，重复启动显示并聚焦现有主窗口。托盘和前端设置通过事件同步。退出仅结束客户端，服务端及其插件生命周期独立。

实现参考：[Tauri 系统托盘](https://v2.tauri.app/learn/system-tray/)与[单实例插件](https://v2.tauri.app/plugin/single-instance/)。

## 实际边界与剩余问题

- 端口检测从部署服务端发起，不是客户端对远端的端到端连通性证明。网络拓扑、FRP、域名及部分存储页面仍有演示内容；尚未实现设备自动发现、跨 NAT 组网、隧道编排或远程桌面会话。本次没有把这些功能标为已实现。
- SSH 地址清单可持久保存到设备列表；密码和私钥仅保留在客户端内存，不写入设备数据库。新选择另一设备会替换当前单终端会话。
- Windows 实测不等同于 Linux/macOS 托盘验证；系统托盘右键各菜单项以原生编译检查和事件实现为依据，本轮自动化未逐项点击系统通知区菜单。
- Linux GTK 间接依赖仍锁定 glib 0.18.5，GitHub 的 VariantStrIter 告警仍开放，修复版本为 0.20.0。不能直接跨版本替换 Tauri/GTK 依赖；未将该上游告警标为已修复。告警参考：[gtk-rs 修复](https://github.com/gtk-rs/gtk-rs-core/pull/1343)。
- Web 主包仍有体积提示，未生成签名安装包。
