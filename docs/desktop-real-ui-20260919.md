# 托盘与真实界面修复（2026-09-19）

## 可用功能

- 托盘可恢复或隐藏窗口，打开仪表盘、设备管理、设备连接视图、SSH、插件管理和设置，以及切换关闭驻留和退出客户端。设置页提供“立即隐藏到托盘”；原生托盘不可用时禁止隐藏。重复启动唤回同一实例。
- 连接视图从设备 API 读取登记记录，展示服务端 TCP 检测结果、检测时间与延迟，可进入设备管理或发起 SSH。没有登记设备时显示真实空状态；请求失败时清除过期节点。连线不表示物理网络、VPN 或跨 NAT 隧道。
- 流量监控读取服务端网卡计数；插件列表定期读取真实状态。插件详情读取及保存实际 JSON 配置、展示后端运行日志，移除虚构的评分、下载数、发布历史和无效市场入口。
- 控制台以服务端状态为准，HTTP 错误和业务失败不会显示启动成功。仅嵌入本地服务端提供的 HTTP(S) 回环控制台地址，远程设备使用 SSH。
- ttyd 不再将端口占用或磁盘上的 PID 当成自身运行的证据，停止操作仅作用于其持有的子进程。运行中拒绝更改 ttyd 配置以免丢失子进程句柄；被插件拒绝的配置不会写入文件。

## 未接入模块

FRP、DNS/证书、WebDAV/SFTP 文件管理、后台下载队列尚未实现。已删除示例隧道、域名、文件、下载进度和仅改变前端状态的成功提示；这些页面及导航显示“未接入”。无效缩放控件和网络设置占位入口已移除。此次并未实现跨 NAT 组网或文件传输。

## 启动

本机双击仓库根目录 `Start-R-Link.cmd`。脚本先验证或启动 `127.0.0.1:8210` 上的 R-Link Server，再启动桌面应用。服务健康时复用进程；端口被其他服务占用时返回错误，不终止已有进程。服务器日志保存在 `logs/server-*.log`。

脚本使用 `.venv/Scripts/python.exe`。默认先寻找本机已构建的 `.repository-consolidation-local/bin/R-Link.exe`，再寻找标准 Cargo release/debug 路径。其他构建目录可传入 `scripts/start-local.ps1 -DesktopPath <exe>`。本机二进制和日志不进入 Git；新克隆仓库需先安装依赖并构建。

关闭窗口默认驻留，使用托盘菜单“退出 R-Link”结束客户端；服务端独立运行。源码修改保留在现有 `main` 工作区，没有创建其他分支。
