## 修复

- 根目录统一开发、测试、构建入口，移除与应用无关的 Codex/JSR 依赖；修正文档、端口与实际目录。
- 插件、插件源及本机控制台需要管理员权限。管理员身份只读取服务端允许名单或 Supabase `app_metadata`，不信任用户可写的字段。
- 插件上传/卸载拒绝路径穿越，ZIP 拒绝符号链接和超限解压；以清单名称安装根目录/嵌套目录包；临时目录按请求隔离，拒绝静默覆盖已安装插件。
- 修复二进制插件被 Python 扫描覆盖、未启动插件误报运行、Python 插件详情返回 500、重载后控制台继续持有旧管理器、退出时 Python 插件未清理。
- SSH 改用 AsyncSSH `create_process(term_size=...)`；修复读任务等待自身、未关闭 WebSocket/连接记录等清理问题；按账号隔离连接列表和关闭操作。
- SSH 强制提供密码/私钥，禁用服务端本地密钥与 agent 自动认证，恢复主机密钥校验；增加握手等待时间和并发上限，修复票据过期边界与畸形输入。
- 服务端路径与启动目录解耦，限制默认 CORS 来源，生产默认关闭热重载，内部错误不返回异常细节；资源采样在线程池执行，避免阻塞事件循环。
- 修复 ttyd 启动变量名/工作目录错误，默认仅监听回环地址并关闭自动 nginx 代理；控制台启动时初始化插件。
- 前端改用标准 npm 导入，修复缺失图标导入、错误回调、Supabase 类型及订阅载荷、拓扑类型、插件状态类型、重启按钮和假卸载成功提示；修复取消请求误报超时及终端资源释放。
- Web 构建加入严格 TypeScript 检查（未使用符号属于单独的代码清理范围）；Deno 服务源码不参加浏览器类型检查。补充插件下载计数 RPC 迁移文件。
- 修正 Tauri 的 `bundle.targets` 格式，生成可追溯到 SVG 的桌面图标，消除库/程序调试符号文件重名，并修正高 DPI 屏幕初始尺寸。
- Vitest 升级为 4.1.11，修复 [GHSA-82fw-gwwq-j7x9](https://github.com/advisories/GHSA-82fw-gwwq-j7x9)。升级后的 npm 安装审计为 0 项漏洞；后续独立 audit 请求曾遇到网络中断。
- 迁移校验验证来源原件，允许运行代码继续维护；同时检查暂存区与工作区原件，CI 执行全部后端回归测试。

## 部署与限制

实际部署需配置 Supabase、管理员 UUID、SSH known_hosts；数据库升级须按顺序应用 `001_initial_tables.sql` 和 `002_plugin_downloads.sql`。本次没有操作线上数据库。ttyd 若通过外部代理开放，必须由部署方配置身份校验；自动代理默认关闭。

原生签名安装包、macOS/Linux 打包以及真实 Supabase/SSH/第三方二进制联调未验证。仍有部分演示页面，Web 主包约 1 MB，构建会提示进一步拆包；不能据此视为全部远程连接功能已完成。
