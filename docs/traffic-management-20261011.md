# 网络流量管理

在左侧“流量管理”打开统一页面。网卡数据来自 R-Link API 服务端的系统接口；Clash 数据来自该服务端已接入的 Clash/Mihomo 控制器。远程部署时，这些数据对应远程服务端及其控制器。

## 网卡流量与健康状态

选择网卡查看当前发送/接收 Mbps、累计发送/接收字节和最近 60 个速率样本。每 5 秒读取系统计数器，通过两次采样之间的字节差与实际时间差计算速率。

同时展示系统报告的链路速率、MTU、收发包数、错误及丢包累计计数。虚拟接口或系统没有提供的字段显示未知；链路速率是接口属性，实际吞吐以采样速率为准。切换网卡、系统重启、计数回退或采样中断会清空旧速率并重新采样。

## Clash 流量与连接管理

先在“Clash 代理”接入控制器，或启动 R-Link 独立内核。连接后，流量管理页面每 2 秒读取连接快照，展示总上传/下载速率、内核累计流量、活动连接、各连接速率，以及按应用和目标汇总的当前连接流量。速率是两次快照之间的平均字节速率。

可以搜索目标、来源或应用，筛选协议并排序；对单条或选中的多条连接执行明确确认后的断开。批量操作逐条执行，部分失败会显示结果，成功关闭的连接从下一次快照移除。断开只影响当前连接，应用可能重新建立连接。

暂停采样适用于检查当前快照；手动刷新可读取新快照。第一次采样、控制器切换、累计计数回退或间隔超过 30 秒时重新建立速率基线。控制器不可达时显示错误，不沿用旧速率。

按应用统计依赖内核识别进程；未提供名称时归入未知应用。应用和目标汇总来自当前活动连接，关闭后的连接不会留在分组统计中。内核累计流量包含已关闭连接，重启后可能归零。这些计数未持久化为按日或按月账单。

## 接口

`GET /api/system/network` 沿用服务访问认证，返回服务端接口、时间、启动时间、字节和健康计数。

`GET /api/clash/traffic` 沿用 Clash 服务访问认证，读取内核 `/connections` 后返回白名单数据：

| 字段 | 含义 |
| --- | --- |
| `sampled_at` | 服务端采样时间，Unix 秒 |
| `source_id` | 控制器采样来源的非敏感标识，用于重建速率基线 |
| `downloadTotal` / `uploadTotal` | 内核累计收发字节 |
| `connections` | 活动连接白名单，包括协议、来源、目标、应用名、字节计数及代理链 |
| `total_connections` | 内核快照中的活动连接数 |
| `truncated` | 是否因连接列表上限而截断；截断时分组统计只代表返回部分 |

断开使用 `/api/clash/connections/{id}` 与 `/api/clash/connections` 的 DELETE 接口。流量管理页带上快照的 `source_id`；来源变化时服务端返回 409，要求刷新后重新确认。批量断开最多并发 4 条请求。控制器密钥、原始连接元数据和应用完整路径不返回浏览器；控制器响应有大小与超时限制。

协议依据：[Mihomo 连接 API](https://wiki.metacubex.one/en/api/#connections)。当前采用连接累计值差分采样；Mihomo 自身 `/traffic` 持续流没有直接转发给浏览器。

## 范围与验证

此功能提供真实流量可视化和当前连接管理。[设备限速与 QoS](device-qos-20261011.md) 使用 Linux 网关原生整形，需配置实际流量经过的接口与执行权限。当前功能不自动修改系统路由、系统代理或防火墙，不包含配额强制执行或持续阻断。NetBird 访问策略仍在“虚拟组网”管理。

```sh
.venv/bin/python -m pytest R-Link-Server -q
npm test
npm run build
R_LINK_RUN_CLASH_INTEGRATION=1 \
R_LINK_MIHOMO_BINARY='/absolute/path/to/mihomo' \
.venv/bin/python -m pytest R-Link-Server/test_traffic_integration.py -q
```

真实内核测试使用独立数据目录、回环代理入口与 TCP 回显服务，检查累计收发量、活动连接字节数，以及关闭一条连接后另一条保留、关闭全部后列表清空。测试实例独立启动和停止。

2026-10-11 本机验证结果：后端 215 项通过、4 项按环境跳过；前端 73 项通过，原生窗口单元测试 12 项通过；类型检查与生产构建通过；独立 Mihomo 流量集成测试 1 项通过。浏览器使用真实回环 TCP 回显连接验证速率、暂停采样、手动刷新、搜索和批量确认断开，活动连接从 2 条降为 0 条。测试内核与临时配置均已清理。此验证覆盖本机服务端与浏览器，未包含跨平台运行或设备 QoS 验收。
